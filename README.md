# A/B Test Analysis — Marketing Experiment

**Level:** Intermediate
**Goal:** Analyse the results of an A/B test on a marketing email campaign and
determine, with statistical rigor, whether a new email design ("treatment")
outperforms the existing design ("control") in conversion rate and revenue.

## Project Overview

A marketing team ran an experiment where users were randomly assigned to
receive one of two promotional emails:

- **Control** — the existing email design
- **Treatment** — a new email design

For each user we recorded whether they converted (made a purchase), how much
revenue they generated, their device type, time spent on the landing page,
and signup date.

This project walks through a complete, reproducible A/B test analysis:

1. Exploratory data analysis (conversion rates, revenue distributions, device
   breakdown)
2. **Power analysis** — was the experiment large enough to detect a
   meaningful effect? What is the minimum detectable effect given the actual
   sample sizes?
3. **Significance testing**:
   - Two-proportion z-test and chi-square test for conversion rate
   - Welch's t-test and Mann-Whitney U test for revenue per user
   - Confidence interval for the difference in conversion rates
4. A final recommendation based on the combined evidence

## Dataset

`data/raw_experiment_data.csv` contains 10,000 simulated users (5,000 per
group) with the following columns:

| Column              | Description                                             |
|---------------------|----------------------------------------------------------|
| `user_id`           | Unique user identifier                                   |
| `group`             | `control` or `treatment`                                 |
| `converted`         | `1` if the user made a purchase, else `0`                |
| `revenue`           | Revenue generated by the user (`0` if not converted)     |
| `device`            | `mobile`, `desktop`, or `tablet`                          |
| `time_on_page_sec`  | Seconds spent on the landing page                        |
| `signup_date`       | Date the user signed up (Jan 2024)                       |

The data is synthetically generated (see the generator logic referenced in
the notebook) with a true underlying conversion-rate lift of ~2 percentage
points for the treatment group, so the analysis has a realistic, detectable
effect to uncover — while still being subject to normal sampling noise.

## `src/power_analysis.py`

| Function | Purpose |
|---|---|
| `required_sample_size_proportions(baseline_rate, minimum_detectable_effect, alpha, power)` | Minimum per-group sample size needed to detect a given lift |
| `achieved_power_proportions(baseline_rate, observed_rate, n_control, n_treatment, alpha)` | Statistical power actually achieved given the observed effect and sample sizes |
| `minimum_detectable_effect(baseline_rate, n_per_group, alpha, power)` | Smallest lift detectable with the sample size you have |

## `src/significance_test.py`

| Function | Purpose |
|---|---|
| `two_proportion_z_test(conversions, n_obs, alpha, alternative)` | Z-test comparing two conversion rates |
| `chi_square_test(contingency_table, alpha)` | Chi-square test of independence (group × outcome) |
| `welch_t_test(sample_a, sample_b, alpha, alternative)` | Compares means of a continuous metric (e.g. revenue), unequal variances |
| `mann_whitney_u_test(sample_a, sample_b, alpha, alternative)` | Non-parametric alternative to the t-test, robust to skew/zero-inflation |
| `confidence_interval_proportion_diff(conversions, n_obs, confidence)` | CI for the difference between two proportions |
| `summarize_group_metrics(df, group_col, conversion_col, revenue_col)` | Quick per-group summary table (n, conversions, rate, avg revenue) |

All tests return a `TestResult` dataclass with `statistic`, `p_value`,
`significant`, and a `details` dict of relevant metrics — so results can be
printed directly or consumed programmatically.

## Getting Started

1. **Create a virtual environment (recommended):**
   ```bash
   python3 -m venv venv
   source venv/bin/activate   # On Windows: venv\Scripts\activate
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the analysis:**
   ```bash
   jupyter notebook notebooks/ab_test_analysis.ipynb
   ```
   The notebook has already been run end-to-end and includes saved outputs
   and charts, so you can also just open it to read the results without
   re-running anything.

4. **Use the utilities directly in your own scripts:**
   ```python
   import sys
   sys.path.append("src")

   import pandas as pd
   from significance_test import two_proportion_z_test, summarize_group_metrics
   from power_analysis import required_sample_size_proportions

   df = pd.read_csv("data/raw_experiment_data.csv")
   summary = summarize_group_metrics(df)

   result = two_proportion_z_test(
       conversions=(int(summary.loc["control", "conversions"]), int(summary.loc["treatment", "conversions"])),
       n_obs=(int(summary.loc["control", "n"]), int(summary.loc["treatment", "n"])),
   )
   print(result)
   ```

## Key Results (from the included run)

- Control conversion rate: **9.86%** (n=5,000)
- Treatment conversion rate: **11.58%** (n=5,000)
- Absolute lift: **+1.72 percentage points** (95% CI ≈ [0.51%, 2.93%])
- Two-proportion z-test: **p ≈ 0.0054** → statistically significant at α=0.05
- Chi-square test: **p ≈ 0.0060** → confirms the z-test result
- Achieved statistical power for the observed lift: **≈ 79%**
- Revenue per user (Welch's t-test): **p ≈ 0.00016** → significant
- Revenue per user (Mann-Whitney U, robustness check): **p ≈ 0.0033** → significant

**Recommendation:** Roll out the new email design (treatment) — both the
conversion-rate lift and the revenue improvement are statistically
significant, and the experiment was reasonably well-powered to detect the
observed effect.

## Notes & Caveats

- This project uses simulated data for demonstration; conclusions are for
  illustration and not derived from a real marketing campaign.
- The two-proportion z-test and chi-square test are mathematically
  equivalent for a 2×2 table (they will agree here) — both are included to
  demonstrate two common, related approaches.
- In practice, decide your significance threshold (α) and required sample
  size (via a power analysis) *before* running the experiment, and avoid
  repeatedly checking results mid-experiment without correcting for multiple
  looks ("peeking"), which inflates the false-positive rate.
